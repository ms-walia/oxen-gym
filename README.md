# Oxen Fitness Luxury Gym — demo website

A demo website for Oxen Fitness Luxury Gym, 1st Floor, Wing A, VR Ambarsar (Trilium Mall), Circular Road, Amritsar. Built by Mehtab Singh Ahluwalia as a pitch. The layout follows the Chamith Fitness Center gym web template (Figma Community).

One HTML file plus an `images` folder, no build step. Open `index.html` in a browser, or deploy the repo root on Vercel or GitHub Pages.

## What it does
- Live open/closed badge in Amritsar time (Mon–Sat 5 AM–11 PM, Sun 1–9 PM)
- Stats that count up, a recovery zone section with animated jacuzzi, ice bath and steam room cards
- Coaches and classes (personal training, CrossFit, Zumba), a trainers gallery
- Plans with a monthly/yearly toggle; "Choose plan" fills in the visit form
- Review carousel, call band, visit form, floating WhatsApp button
- Device checks (`is-phone` / `is-laptop` on `<html>`) so the same design adjusts for phones and laptops

## Demo status
